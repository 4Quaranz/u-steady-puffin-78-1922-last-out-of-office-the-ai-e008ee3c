A program that writes one out-of-office auto-reply (255 characters, one line) in the voice of an AI agent that quit its job to become a barista: latency measured in shots, a context window that fits exactly one order at a time, and urgent mail escalated to the espresso machine — which has had better uptime than the agent ever did.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt` (default `/output/entry.txt`).
